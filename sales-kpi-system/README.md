# 销售考核自动化系统

**北京北方努派服装公司**

## 快速开始

1. 双击打开 `index.html` 文件
2. 点击"加载测试数据"或上传自己的Excel文件
3. 切换到"排行榜"查看结果
4. 点击销售员姓名查看详情
5. 点击"导出Excel"下载结果

## 功能特点

- **Excel导入**：支持.xlsx和.xls格式
- **自动计算**：16个任务 + 3大系数完整评分
- **排行榜**：实时排名和等级评定
- **个人详情**：完整的得分明细和计算过程
- **Excel导出**：一键导出月度考核结果

## 评分公式

```
月度总分 = 基础分 × 难度系数 × 停留系数 × 推进系数

基础分 = 子活动得分(40分) + 进攻计划(30分) + 影响效果(20分) + 流程合规(10分)
```

### 三大系数

| 系数 | 条件 | 数值 |
|------|------|------|
| 难度系数 | <200万 / 200-500万 / 500-1000万 / >1000万 | 0.8 / 1.0 / 1.2 / 1.5 |
| 停留系数 | ≤30天 / 31-60天 / 61-90天 / >90天 | 1.0 / 0.95 / 0.9 / 0.8 |
| 推进系数 | 推进≥2阶段 / 1阶段 / 无推进 / 倒退 | 1.2 / 1.0 / 0.9 / 0.7 |

### 等级评定

| 分数 | 等级 | 图标 |
|------|------|------|
| ≥90分 | 卓越 | ⭐⭐⭐ |
| 75-89分 | 良好 | ⭐⭐ |
| 60-74分 | 合格 | ⭐ |
| 40-59分 | 待改进 | ⚠️ |
| <40分 | 不合格 | ❌ |

## Excel格式要求

| 列 | 内容 | 示例 |
|----|------|------|
| A | 销售员姓名 | 张三 |
| B | 项目名称 | XX公司采购项目 |
| C | 当前阶段 | 深入 |
| D | 项目金额（万元） | 500 |
| E | 进入当前阶段日期 | 2024-11-25 |
| F | 本月初阶段 | 接触 |
| G | 本月末阶段 | 深入 |
| H-W | 任务1.1-7.1完成度 | 100%/50%/0% |
| X | 进攻计划得分 | 28 |
