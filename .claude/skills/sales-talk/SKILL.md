# Sales Talk Skill - 客户推进话术生成器

## 概述

为B2B销售场景生成结构化的客户推进话术包，适用于职业装/工服采购等央国企招投标场景。

## 输入参数

| 参数 | 必填 | 说明 |
|------|------|------|
| 客户/系统 | 是 | 目标客户名称或所属系统 |
| 项目类型 | 是 | 如：职业装框架采购、工服招标等 |
| 当前阶段 | 是 | 接触/深入/方案/投标前/投标/商务/交付 |
| 对象角色 | 是 | 沟通对象的职位/角色 |
| 目标下一步 | 是 | 本次沟通希望达成的具体目标 |
| 我方优势 | 是 | 可用于话术的差异化优势点 |
| 约束 | 否 | 特殊限制（如不谈价格、语气要求等） |

## 输出结构

### 话术包内容

1. **开场白** - 破冰/建立连接
2. **价值铺垫** - 引出话题的过渡语
3. **核心话术** - 围绕目标的主要沟通内容
4. **应对异议** - 常见拒绝场景的应对
5. **收口话术** - 引导下一步行动
6. **备用方案** - 退而求其次的替代目标

### 输出格式

- Markdown格式
- 每段话术提供2-3个可选版本
- 包含场景说明和使用建议
- 标注关键动作和时机

## 使用示例

```
请使用 sales-talk skill 生成一套客户推进话术包。

【客户/系统】国家电网
【项目类型】职业装框架采购
【当前阶段】投标前
【对象角色】办公室服装管理员
【目标下一步】获取详细需求表
【我方优势】央国企案例丰富、交付准时率高
【约束】语气正式，不主动谈价格
```

## 话术原则

1. **价值导向** - 先给价值，再提要求
2. **角色适配** - 根据对象角色调整措辞
3. **留有余地** - 不把话说死，保持灵活
4. **专业克制** - 避免过度推销感
5. **行动明确** - 每段话术有明确的目标指向
