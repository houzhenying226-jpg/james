# 批次1：4张MVP多维表格

> 钉钉多维表格自动建表方案，包含表结构定义、自动化脚本和手动建表指南。

## 概览

| 表名 | 表ID | 字段数 | 填写人 | 触发阶段 |
|------|------|--------|--------|----------|
| 成交项目交接表 | project_handover | 22 (5+17) | 销售 | S05签约确认 |
| 量体申请 | measurement_apply | 17 (5+12) | 销售 | S06量体启动 |
| 制作明细表 | order_detail | 20 (5+15) | 销售/商务 | S07下单确认 |
| 签收单 | delivery_receipt | 18 (5+13) | 商务 | S10/S11签收确认 |

## 文件结构

```
multidimensional-tables/
├── README.md                            # 本文件
├── create_tables.py                     # 自动化建表脚本
└── schemas/
    ├── common_fields.json               # 5个通用字段定义
    ├── 01_project_handover.json         # 成交项目交接表 schema
    ├── 02_measurement_apply.json        # 量体申请 schema
    ├── 03_order_detail.json             # 制作明细表 schema
    └── 04_delivery_receipt.json         # 签收单 schema
```

## 使用方式

### 方式一：自动化脚本（推荐）

```bash
# 1. 安装依赖
pip install requests

# 2. 查看表结构摘要（无需API凭证）
python create_tables.py --summary

# 3. 导出完整JSON（可用于其他工具导入）
python create_tables.py --export-json tables_export.json

# 4. 通过钉钉API自动创建（需要配置凭证）
export DINGTALK_APP_KEY="your_app_key"
export DINGTALK_APP_SECRET="your_app_secret"
export DINGTALK_SPACE_ID="your_space_id"
python create_tables.py
```

### 方式二：手动建表

参考下方每张表的字段清单，在钉钉中手动创建。

## 通用字段（每张表的前5个字段）

| # | 字段名 | 类型 | 必填 | 说明 |
|---|--------|------|------|------|
| 1 | 项目编号 | 单行文本 | 是 | 格式：PRJ-2026-001 |
| 2 | 提交人 | 成员 | 是 | 选钉钉通讯录 |
| 3 | 提交日期 | 日期 | 是 | 默认今天 |
| 4 | 审核状态 | 单选 | 否 | ⏳待审核 / ✅已通过 / ❌已驳回 |
| 5 | 审核意见 | 多行文本 | 否 | 系统回写驳回原因 |
